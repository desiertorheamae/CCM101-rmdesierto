# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

I recommend AWS because it offers many services that can support a startup's mobile application. The company has a limited budget, so it can start with the resources it needs and increase them as the application gains more users. AWS also provides services that can support the application as the business grows. The company can use Amazon EC2 for computing, Amazon S3 for storage, and Amazon RDS for its database.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

### Recommended Platform: Microsoft Azure

I recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with existing Microsoft technologies, which can make the transition to cloud services easier. The university can move some of its services to Azure without completely changing its current environment. It can use Azure Virtual Machines, Microsoft Entra ID, and Azure Blob Storage for its cloud needs.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Blob Storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

I recommend Google Cloud because the company focuses on Artificial Intelligence and Machine Learning. Google Cloud provides services that can support both AI development and high-performance computing. The company can use Compute Engine for demanding workloads, Vertex AI for developing AI and machine learning applications, and Google Kubernetes Engine for managing containerized applications.

### Recommended Services

- Compute Engine
- Vertex AI
- Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

I recommend AWS because the company needs reliable infrastructure that can serve customers in different parts of the world. AWS provides services that can help keep applications available and adjust resources when customer traffic changes. The company can use Amazon EC2 for computing, Elastic Load Balancing for distributing traffic, and Amazon EC2 Auto Scaling for adjusting resources based on demand. These services can help the company handle high traffic during busy periods.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- Amazon EC2 Auto Scaling

---

## Summary

| Client | Recommended Platform | Main Reason |
|---|---|---|
| Client A – Startup | AWS | Flexible and scalable services |
| Client B – University | Microsoft Azure | Microsoft technology integration |
| Client C – AI Research Company | Google Cloud | AI and Machine Learning services |
| Client D – Global E-Commerce | AWS | Availability and automatic scaling |
