# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides different services that allow individuals and organizations to run applications, store data, manage networks, and use computing resources through the internet.

## Global Infrastructure

AWS has a global infrastructure made up of Regions and Availability Zones. A Region represents a separate geographic area, while Availability Zones are separate locations within a Region. This structure helps organizations improve application availability, reduce delays, and protect workloads from failures. AWS also provides additional infrastructure such as Local Zones and Wavelength Zones for specific use cases.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can search for services, create and manage resources, check account information, monitor resources, and manage billing through the console.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers that can be used to run applications and other workloads.

2. **Amazon S3 (Simple Storage Service)** – Provides object storage for files, backups, websites, applications, and other types of data.

3. **Amazon VPC (Virtual Private Cloud)** – Allows users to create an isolated virtual network for their AWS resources.

4. **AWS IAM (Identity and Access Management)** – Controls who can access AWS resources and what actions they are allowed to perform.

## Three (3) Advantages

1. **Wide range of services** – AWS provides many services that can support different technical and business requirements.

2. **Global infrastructure** – AWS has Regions and Availability Zones in different parts of the world, allowing organizations to deploy applications closer to their users.

3. **Scalability** – AWS resources can be increased or reduced depending on the workload and requirements of an organization.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for application hosting, website development, data storage, backup and recovery, data analytics, and disaster recovery. It can also support applications that need to handle changing workloads and large numbers of users.
