# Laboratory 09 – Cloud Automation Engineer

## Overview

This laboratory focuses on automating application data backups in a Linux environment using Bash scripting, file compression, and cron scheduling.

## Objectives

- Understand the fundamentals of Bash scripting, variables, and cron jobs.
- Create a sample application data directory.
- Develop and test an automated backup script.
- Schedule backups to run every night at 2:00 AM.
- Document the implementation and results using Markdown and screenshots.

## Laboratory Contents

- `automation-research.md` – Research on Bash scripts, variables, and cron jobs.
- `backup-script-guide.md` – Instructions for creating, testing, and scheduling the backup script.
- `reflection.md` – Personal reflection on the laboratory activities.
- `screenshots/` – Screenshots showing the implementation and testing results.

## Expected Outcome

A working Bash script that compresses the application data directory into a timestamped `.tar.gz` backup archive and a cron job configured to execute the script automatically every night at 2:00 AM.
