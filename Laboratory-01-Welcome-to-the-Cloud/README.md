# Laboratory 01 – Welcome to the Cloud

This laboratory introduces the basic Linux environment and cloud computing workspace. In this activity, I learned how to access a Linux environment, create and manage directories and files, gather system information, and document my work using Markdown.

## Activities Completed

* Accessed the Linux environment using KillerCoda
* Created and configured a Linux user account
* Gathered basic system information
* Created and organized directories
* Created Markdown documentation
* Prepared a GitHub portfolio for future laboratory activities
