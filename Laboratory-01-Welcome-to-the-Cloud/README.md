# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the Linux environment and cloud computing workspace. The mission is to become familiar with the Ubuntu Linux environment, basic Linux commands, file and directory management, system information, and proper documentation using Markdown.

## Objectives

- Become familiar with the Ubuntu Linux environment.
- Learn and practice basic Linux commands.
- Create and manage files and directories.
- Gather and document system information.
- Practice using Markdown for documentation.
- Organize laboratory outputs and screenshots in GitHub.

## Activities Performed

During this laboratory, I performed the following activities:

1. Accessed and explored the Ubuntu Linux environment.
2. Created and managed directories and files using Linux commands.
3. Checked system information and documented the results.
4. Created Markdown files for the laboratory requirements.
5. Organized screenshots and laboratory files in the GitHub repository.
6. Documented the activities and learning outcomes in Markdown.

## Linux Commands Used

| Command | Purpose |
|---|---|
| `pwd` | Displays the current working directory. |
| `ls` | Lists files and directories. |
| `ls -la` | Displays detailed information, including hidden files. |
| `cd` | Changes the current directory. |
| `mkdir` | Creates a new directory. |
| `touch` | Creates a new empty file. |
| `rmdir` | Removes an empty directory. |
| `rm` | Removes files. |
| `cat` | Displays the contents of a file. |
| `whoami` | Displays the current user. |
| `uname` | Displays system information. |
