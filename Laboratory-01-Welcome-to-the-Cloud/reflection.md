# Reflection

This laboratory helped me understand the basic concepts of working in a Linux environment and using cloud-based tools. I learned how to access KillerCoda, create and manage a Linux user account, check system information, and organize files and directories using Linux commands. I also learned how to use Markdown for documentation and GitHub to create a Cloud Computing portfolio.

Through this activity, I realized that proper organization and documentation are important skills for a cloud engineer. Creating this portfolio will allow me to keep my laboratory activities organized and track my progress throughout the semester.
