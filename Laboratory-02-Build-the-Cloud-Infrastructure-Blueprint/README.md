## Build the Cloud Infrastructure Blueprint
## Mission Overview

The mission of this laboratory activity is to document the technical work completed in the cloud computing environment. The activity focuses on understanding cloud infrastructure, using Linux commands, working with development tools, and documenting the procedures and skills gained during the laboratory exercises.

## Objectives

* Understand the basic components of cloud infrastructure.
* Identify and use common cloud infrastructure services and resources.
* Execute Linux commands for system administration and file management.
* Use appropriate development and cloud computing tools.
* Document technical procedures using proper Markdown formatting.
* Develop practical skills in managing and working with cloud-based environments.

## Cloud Infrastructure Components

The laboratory activity involved the following cloud infrastructure components:

* **Compute Resources** – Used to run applications, services, or laboratory workloads.
* **Storage** – Used to store files, project resources, and other required data.
* **Networking** – Provides communication between cloud resources and external systems.
* **Operating System** – A Linux-based environment was used for executing commands and managing resources.
* **Cloud Services** – Cloud-based resources and services were used to support the laboratory activities.

## Tools Used

* **Git** – Used for version control and tracking changes.
* **GitHub** – Used to store and manage the laboratory repository.
* **Linux Terminal** – Used to execute commands and manage files.
* **Cloud Computing Environment** – Used to access and manage cloud-based resources.
* **Markdown** – Used to format and document the README file.

## Linux Commands Executed

The following Linux commands were used during the laboratory activities:

```bash
pwd
ls
cd
mkdir
touch
cp
mv
rm
cat
clear
```

These commands were used for navigating directories, creating and managing files and folders, viewing file contents, and maintaining the working environment.

## Skills Learned

* Basic cloud infrastructure management.
* Linux command-line navigation and file management.
* Git and GitHub repository management.
* Markdown documentation and formatting.
* Basic troubleshooting and problem-solving.
* Organizing technical information in a structured README file.
* Understanding how different cloud infrastructure components support computing tasks.

## Challenges Encountered

Some challenges encountered during the laboratory activity included becoming familiar with Linux commands, navigating the cloud environment, and ensuring that files were correctly managed within the project repository. Another challenge was maintaining proper Markdown syntax and organizing the README so that all required technical information was presented clearly.

These challenges were addressed through practice, reviewing command usage, checking repository contents, and carefully following the laboratory instructions.
