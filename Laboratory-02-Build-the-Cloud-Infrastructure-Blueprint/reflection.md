# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think **compute resources** are one of the most important cloud infrastructure components because they provide the processing power needed to run applications, services, and workloads. Without compute resources, other components such as storage and networking would not be able to support running applications effectively. Compute resources also allow organizations to scale their systems depending on their needs.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable and flexible operating system for managing cloud servers and applications. It allows users to control systems through the command line, manage files and processes, configure services, and perform administrative tasks. Because Linux is widely used on cloud platforms, learning Linux commands is an important skill for working with cloud infrastructure.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure, configurations, commands, and procedures that need to be followed. It helps prevent mistakes and makes troubleshooting easier. Good documentation also allows other team members to understand the system and repeat the deployment process when necessary.

## 4. What new skills did you learn during this laboratory activity?

During this laboratory activity, I learned how to use basic Linux commands, manage files and directories, work with Git and GitHub, and organize technical information using Markdown. I also gained a better understanding of cloud infrastructure components and the importance of documenting technical work.

My GitHub portfolio has improved because it now contains more organized laboratory activities, technical documentation, and reflections.
