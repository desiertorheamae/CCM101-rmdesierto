# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud storage and the deployment of an Object Storage server using MinIO. The activity provided hands-on experience in deploying a storage server, accessing its web console, creating a bucket, and uploading a file.

## Objectives

- Understand the different types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Deploy an Object Storage server using Docker.
- Access the MinIO Web Console.
- Create and manage a storage bucket.
- Upload a sample file to the bucket.
- Document the deployment process.

## Tools Used

- KillerCoda Ubuntu
- Docker
- MinIO
- MinIO Web Console
- Git
- GitHub
- Google Chrome

## Skills Learned

- Understanding different types of cloud storage.
- Deploying an Object Storage server using Docker.
- Using environment variables to configure a Docker container.
- Accessing and managing the MinIO Web Console.
- Creating buckets and uploading files.
- Documenting cloud storage deployment procedures.
- Using Git and GitHub for version control.
